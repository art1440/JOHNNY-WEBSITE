# Photos

Drop images in this folder with these exact names and they appear on the site automatically.
Until a file exists, a dashed "Add photo" placeholder shows instead.

| File | Where it shows | Suggested size |
|---|---|---|
| `agent.jpg` | Home → "How it works" portrait frame | 1000×1250 (4:5, portrait) |
| `featured-family.jpg` | Testimonials → featured story | 1500×1200 (5:4) |
| `featured-avatar.jpg` | Testimonials → featured story avatar | 200×200 (square) |
| `client-1.jpg` … `client-6.jpg` | Testimonial card avatars (in order) | 200×200 (square) |

Only use client photos and reviews you have permission to publish.
